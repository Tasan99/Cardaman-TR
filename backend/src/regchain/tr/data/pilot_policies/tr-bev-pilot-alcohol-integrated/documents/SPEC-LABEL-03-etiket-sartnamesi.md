# Etiket ve Ambalaj Şartnamesi

Belge no: SPEC-LABEL-03 — Sürüm 2.1 — Sahibi: Kalite Güvence Müdürlüğü — Kapsam: Temsili Bira Üretim A.Ş., tüm bira ürünleri

Sentetik test belgesidir; gerçek bir şirketin şartnamesi değildir.

1. İhraç amaçlı üretilenler hariç olmak üzere, alkollü içkilerin ambalajları üzerine zararlarını belirten Türkçe yazılı uyarı mesajları konulur.

2. Hacmen % 1,2’den fazla alkol içeren içeceklerin etiketinde hacmen gerçek alkol derecesi belirtilir.

3. Etiket tasarımları, baskıya gönderilmeden önce Kalite Güvence ve Hukuk birimlerince onaylanır.

4. Alkolsüz bira etiketinde ürünün alkolsüz olduğu belirtilir.

5. Ambalaj malzemeleri gıda ile temasa uygunluk belgesi olan tedarikçilerden temin edilir.
