# Ticari İletişim Esasları

Belge no: POL-COM-11 — Sürüm 2.1 — Sahibi: Kurumsal İletişim Müdürlüğü — Kapsam: Grup (tüm şirketler)

Sentetik test belgesidir; gerçek bir şirketin politikası değildir.

1. Portföyümüzdeki bira, şarap ve distile içkiler için hiçbir mecrada reklam verilmez; tüketiciye dönük tanıtım çalışması yürütülmez.

2. Markalarımız spor kulüplerine ve festivallere sponsor olabilir; bu durumda yalnızca şirketin ticaret unvanı kullanılır.

3. Ürünlerimiz hangi gerekçeyle olursa olsun hediye, eşantiyon veya promosyon olarak ücretsiz verilmez.

4. Kurumsal internet sitemizin ürünler bölümünde markalarımız görsel kullanılmadan liste halinde yer alır.

5. Basın bültenleri yayımlanmadan önce Kurumsal İletişim Müdürlüğünce gözden geçirilir.
